# Security and privacy policy

## Supported version

Security fixes currently target the latest release.

## Reporting

Please report vulnerabilities privately through GitHub Security Advisories after the repository is published. Do not open a public issue containing credentials, personal information or private job-search data.

## Data handling

JobLens is local-first, but users remain responsible for imported data. Do not commit:

- resumes or personal profiles;
- browser cookies or storage state;
- API keys and request/security tokens;
- recruiter private contact information;
- private messages or authenticated page captures;
- job-board data you do not have permission to redistribute.

The default `.gitignore` excludes common private data directories and local databases.
