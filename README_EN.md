# JobLens-CN

JobLens-CN is a local-first company–job intelligence toolkit for importing job postings, normalizing company relationships, tracking JD changes, running explainable candidate matching, and generating reports or a local dashboard.

It ships with synthetic demo data only. No job-board scraper, private resume, browser state, or real recruitment dataset is included.

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
joblens demo
```

See the [Chinese README](README.md) for features, commands, data format, privacy guidance, and roadmap.
